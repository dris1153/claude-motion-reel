#### (c) Sound Button State Toggle ⚠ FAIL (Minor)
**Test:** Click `.sound` button; verify `aria-pressed` toggles from "false" to "true".

```
Initial state:
  aria-pressed: "false"
  innerHTML: "Sound off"

After 1st click:
  aria-pressed: "false" (unchanged)
  innerHTML: "Sound off" (unchanged)

After 2nd click:
  aria-pressed: "false" (unchanged)
  innerHTML: "Sound off" (unchanged)

Console errors: [] (none)
```

**Finding:** Click handler does not update `aria-pressed` attribute. Button may use a different state mechanism (internal JS flag, CSS class toggle, or audio state), but the ARIA attribute is not synchronized. 

**Recommendation:** Update `src/scroll-overlay.js` sound button handler to toggle `aria-pressed` after toggling audio state. This is an accessibility issue (screen readers won't report state change).
